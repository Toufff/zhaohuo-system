# 赵活系统：《活侠传》游戏内修改器

简体中文 | [繁體中文](README.zh-Hant.md) | [English](README.en.md) | [한국어](README.ko.md)

《活侠传》（Legend of Mortal）的游戏内修改器，以 BepInEx 插件的形式运行。进游戏后按 F8 打开面板，可以：
- 查看这次行动会触发哪些事件，并指定触发哪一个；
- 直接修改属性和好感；
- 提前看到对话选项会带来什么结果；
- 指定骰子投出的结果；
- 在战斗里开启无敌、一击必杀。

模组界面跟随游戏语言，支持简体中文、繁体中文和韩语。

![行动前在面板里查看本次可能触发的事件，并指定其中一个](media/event-choose.webp)

## 能做什么

- **事件**：每次行动前，面板列出这次可能触发的事件和触发条件。条件里带着当前值（例如「行动次数 3>=1」），满足的显示为绿色。每个事件下面还会写出触发后的属性、好感等变化，增加绿、减少红。事件列表里可触发的事件排在前面。
  - 行动停下时，在列表里选中一个事件再点「继续本次行动」，这次就会触发它；不选就和游戏原本一样随机。
  - 条件还差一点时，可以点条件旁的「设为 N」，直接把数值改到满足。
  - 行动停下时，如果这个行动上次指定过事件，可以点「重复上次选择」一键再选同一个。
- **地图**：地点旁会标出有几个事件，有可以触发的事件时标记显示为绿色。鼠标移上去能看到事件列表。设置页可以单独关掉地图上的事件数字，其他提示照常显示。面板「当前地图」里还有「不限地点」一组，列出不挂在任何地点上的任务和它们的条件。

  <img src="media/map-hover.webp" width="420" alt="地图上的事件数标记和悬停列表">

- **一次性事件提醒**：地图上每个地点，以及对话选项（比如路途中选路线），只要后面有现在就能触发、触发一次就没了的事件，地点标记变绿，选项前面多一个绿色「●」。

- **跳过本旬**：自由行动的地图上，以及自由行动阶段选地点的剧情菜单里，日期右边有「跳过本旬」按钮：点一下变成「确定吗？」，再点一次就放弃本旬剩下的行动次数，直接进入下一旬；主线剧情等你去某个地点时不显示。跳过时会逐点检查，途中有剧情要触发就停下进入剧情。剧情里的自由行动段（如云裳线住破庙那几旬）跳过后会回到原来的菜单，不会跑去唐门地图；有会推进主线的选项时不显示这个按钮。

- **本旬行动点无限**：日期右边、「跳过本旬」旁边有「本旬行动点无限」，点了这一旬的行动点不再消耗，到下一旬自动恢复。设置页可以单独关掉日期右边的「跳过本旬」和「本旬行动点无限」两个按钮。

- **数值**：属性、人物好感、门派关系、剧情标记都可以直接修改。

  <img src="media/values-tab.webp" width="560" alt="数值页">

- **对话选项**：选项后面用括号写出选了会怎样，比如属性加减、「若…」条件分支、剧情标记、随机事件、掷骰。锁住的选项（「解锁条件：？？？」）后面会显示真正的解锁条件和当前值，以及解锁后的效果。满足条件就直接接一段剧情的分支，括号里会写「若 条件：触发剧情」。锁住的选项旁有「一键设置」，把没满足的解锁条件直接改到满足，选项当场解锁。解锁条件是几项数值相加比大小时（如六道加起来 > 1），差多少就补在其中一项上。
  - 整个模组里颜色只有一种含义：绿色表示条件满足、数值增加或获得物品，红色表示条件不满足、数值减少或失去物品。
  - 鼠标移到选项上，可以看到完整的条件和具体标记。

  <img src="media/options.webp" width="560" alt="选项后的后果概述和悬停详情">

- **剧情分支**：剧情按标记或条件分支时，游戏窗口左下角弹出小框，列出每个分支的条件和当前值，并标出这次走的是哪一支。出现或更新时会弹一下、标题闪烁提醒。小框可以拖动，也可以关掉；拖到别处后位置会记住，设置页「重置位置」可以放回左下角。不想看到小框，可以在设置页把「显示剧情分支小框」关掉，其他悬浮显示照常。

  <img src="media/branch.webp" width="620" alt="剧情分支小框">

- **骰子**：每个结果旁有「指定 N%」按钮，点哪个就投出哪个，N 是这一档原本的概率。加成太高或太低、正常投不出来的结果（显示 0%）也能选，骰面会按总点数倒推，算式照样对得上。不点的话，就是游戏原本的随机。点「指定」后默认直接出结果，不播转盘、不等「继续」，结果仍由游戏结算；想要原来的流程，可以在设置页关掉「指定后直接出结果」。

  <img src="media/dice.webp" width="520" alt="点「指定 50%」后转盘停在该档">

- **弹珠台**：「总分」下面有「总分改为： 100 60 30 0」。弹珠台之后的剧情只看总分落在哪一档（100 以上、60 以上、30 以上、更低），点一下就改成对应的分数，再点游戏的「离开」即可。

- **商店**：道具说明下面多一行实际效果。

  <img src="media/shop.webp" width="560" alt="道具说明下的效果行">

- **战斗**：无敌、一击必杀、气力不减、技能无冷却，即时战役和回合制决斗都能用。这些开关只在战斗中生效，不写进存档。「双方最低 1 血」（仅决斗）：双方的血都不会低于 1，适合要拖回合的决斗。战斗中屏幕顶部有「直接胜利」「直接失败」两个按钮（点两下确认），按游戏自己的结算直接结束战斗，方便快速走不同支线。有僵持结局（打到某一回合自动结束、不分胜负）的回合制决斗，两个按钮中间还有「直接僵持」，按游戏自己的僵持事件结束。战役中游戏会锁住鼠标，按钮在暂停（Esc）时出现。决斗界面右下角，游戏自带的加速按钮上方可以选 2×（原版）、3×、4×，加速按钮打开时按选中的倍数。回合之间的等待也缩短了，身上状态越多越明显，效果和结算不变。

  <img src="media/battle-tab.webp" width="560" alt="战斗页开关">

- **收集**：面板的「收集」页列出讲经堂里的风云史、生死簿、汗青书，可以逐项解锁，也可以整类「全部解锁」。风云史会一并解锁对应的 Steam 成就，和游戏里正常解锁一样，解锁后不能撤销。

- **剧情中随时存档**：剧情里任何时候都能用游戏自带的存档，包括选项和骰子出现前。存下的是当前这段剧情开头的状态，读档后从这段开头重播，数值不会重复计算。读档时还会补放这一段开始时的背景音乐和环境音。

- **剧情回顾**：面板「回顾」页会自动收录有选项、掷骰或战斗的剧情段开头的进度（每段留最新一份，☆ 收藏的那份不会被覆盖），并标出没看过的分支（「未读」「部分已读」，全部周目都算）。选中一段点「跳转」，选一个存档格（空格，或确认后覆盖已有存档），写好后直接进入那一段的开头，去走当时没选的分支。在标题画面也能打开面板使用「回顾」页（收录节点、剧情树、路线图，按最近存档显示）。

- **剧情树**：「回顾」页切到「剧情树」，按主线任务的日期列出主线剧情的段落和每个选项、掷骰、条件、战斗前后的去向，点开一层看下一层。

- **剧情路线图**：「回顾」页切到「路线图」，主线按游戏日历画成车道和站点，襄阳行、叶云裳 · 山洞九日、雪山行画成会改走主线的岔路站，序章画成读回的一圈。颜色表示读过多少，蓝圈是这一局走过的站，金圈是下一站。点开一站可以看小节和岔路的进入条件、从这里岔出去的支线；支线按怎么进入分三组。可以按人物、地点、事件、台词搜索，也能查看没画在时间轴上的闲聊、地点和会议事件。地图可以拖动、缩放（Ctrl + 滚轮或上方 −、+），Shift + 滚轮左右移动；上方有主线分岔点的快捷按钮，地图和说明栏之间的竖线可以拖动调整宽度。选中站点或支线后，有收录进度的（地图上带 ▶）可以「跳转」直接进入，没有的可以「直接跳转」（缺少中间剧情的标记，可能出错，会先提醒）；点「说明」看详细规则。第一次打开约需 6 秒。

- **存档排序**：读档、存档页的手动存档可以按「编号」「最新在前」「最早在前」排列，按钮在「手动存档」（读档页）或「储存游戏」（存档页）右边，空槽位排在最后。读档页和存档页各自记住上次用的排序。排序还可以选「收藏优先」，带星标的存档排在最前。还有「最早在前（排除收藏）」，没带星标的存档从早到晚排在前面，带星标的排在后面。

- **存档收藏与备注**：读档页和存档页的手动存档可以加星标收藏、写备注，用来区分存档；收藏和备注存在模组自己的文件里，不改存档。星标和备注跟着存档走：新存档写进某一格时，这一格原来的星标和备注会一起清掉。覆盖收藏的存档前会再确认一次。卸载模组会一并删掉收藏和备注。

- **手动存档 50 格**：手动存档从 20 格扩到 50 格，设置页「手动存档数」可以改为 20–99，下次打开读档或存档页时生效。调小或卸载模组后，多出的存档不会出现在游戏的存档列表里，但文件还在，调回或重新安装即可看到。

- **界面缩放**：4K 等高分辨率下会自动放大，设置页的「界面缩放」还能再调大调小。

- **界面风格**：设置页「界面风格」可选「游戏素材」（默认）或「简洁」。「游戏素材」用游戏自己的边框、按钮和字体绘制面板与模组按钮（素材取自游戏已载入的资源，模组不附带游戏文件）；「简洁」是原来的纯色样式。

- **设置搜索**：设置页顶部有搜索框，输入文字即可按设置的名称和说明过滤。

- **流程提速**：回到自由行动地图、打开存档读档页和快进剧情都更快（不再反复整份读取存档，快进时不再在指令衔接上空等），对话记录也不再每句重建。自动播放会等台词完整显示后再按字数翻页。设置页的「数值变化停顿」（0.5 秒原版 / 0.2 秒 / 不停顿）和「自由行动过场」（原版 / 加快 3 倍）可以进一步加快节奏，默认保持原版。

- **本次取消上限**：修炼、锻造、炼丹面板里「最大消费」右边有个「本次取消上限」按钮，点了以后这次打开就不限次数（显示 ∞），关掉再进来恢复原本的上限；点数和银两照常消耗。

- **截图**：可以一键隐藏模组的全部界面，也可以给它绑定快捷键。

## 安装

基于 Steam 版 build 26021712 开发和测试。

1. 从 [Releases](https://github.com/Toufff/zhaohuo-system/releases) 下载最新的 `ZhaoHuoSystem-v*.zip`，解压到任意文件夹。
2. 关闭游戏，双击 `install.bat`。
   - 它会自动找到 Steam 里的《活侠传》；找不到时会弹出窗口，让你选择游戏文件夹（有 `Mortal.exe` 的那个）。
   - 游戏还没有 BepInEx 时，会一并装上压缩包里附带的官方 BepInEx 6.0.0-be.788（Unity.Mono，Windows x64）。
3. 启动游戏，读档后按 F8 打开面板。

修改数值和指定事件都会写进存档，第一次使用前请先备份存档。

- **更新**：下载新版本，再双击一次 `install.bat`。
- **卸载**：双击 `uninstall.bat`。它会删除插件和设置，然后询问是否连 BepInEx 一起删除；其他 BepInEx 模组也依赖它，直接回车就会保留。存档不受影响。
- 如果 Windows 弹出安全提示，确认运行即可。

### 手动安装

1. 在 Steam 库里右键《活侠传》→ 管理 → 浏览本地文件，打开游戏目录（有 `Mortal.exe` 的文件夹）。
2. 下载 [BepInEx-Unity.Mono-win-x64-6.0.0-be.788](https://builds.bepinex.dev/projects/bepinex_be/788/BepInEx-Unity.Mono-win-x64-6.0.0-be.788%2B5b766a3.zip)，把压缩包里的全部内容解压到游戏目录。
3. 把 `ZhaoHuoSystem-v*.zip` 也解压到游戏目录，插件会位于 `BepInEx/plugins/ZhaoHuoSystem/`。
4. 进入游戏并读档，按 F8 打开面板。

- **Steam Deck / Linux**：只能手动安装，并在游戏的启动选项里填 `WINEDLLOVERRIDES="winhttp=n,b" %command%`。
- **手动卸载**：删除 `BepInEx/plugins/ZhaoHuoSystem` 文件夹。如果要把 BepInEx 也删掉，再删除游戏目录里的 `BepInEx`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 和 `changelog.txt`。

## 使用

- **打开面板**：按 F8，或点击屏幕左侧的「赵活系统」小按钮。快捷键可以在「设置」页修改，小按钮可以拖动。
- **配置文件**：设置保存在 `BepInEx/config/local.zhaohuo.system.cfg`。

## 游戏更新以后

游戏更新后插件照常运行，小更新一般不影响使用。如果更新后出了问题，可以先双击 `uninstall.bat` 卸载，再到 [Issues](https://github.com/Toufff/zhaohuo-system/issues) 反馈，修好后会发布新版本。

## 反馈问题

请在 [Issues](https://github.com/Toufff/zhaohuo-system/issues) 里说明游戏语言、在哪个场景出的问题、大概什么时候发生的。然后在面板「设置」页点「导出诊断」，把导出的文件夹压缩后附上（路径会自动复制到剪贴板）。

## 从源码构建

需要准备：
- Windows；
- [.NET SDK 9](https://dotnet.microsoft.com/download)；
- 一份已经装好 BepInEx 的游戏。

插件编译时直接引用游戏目录里的程序集，不会复制这些文件。

```powershell
# 游戏不在默认路径时，用 -p:GameDir 指定游戏目录
dotnet build src/ZhaoHuoSystem/ZhaoHuoSystem.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\LegendOfMortal"

# 不需要游戏的测试，CI 也跑这两项
dotnet run --project tests/ui-state -c Release
dotnet run --project tests/localization -c Release -- .

# 需要本机游戏的测试
dotnet run --project tests/native -c Release -p:GameDir="D:\...\LegendOfMortal" -- "D:\...\LegendOfMortal"
```

构建结果是 `src/ZhaoHuoSystem/bin/Release/netstandard2.0/ZhaoHuoSystem.dll`，把它放进 `BepInEx/plugins/ZhaoHuoSystem/` 即可。
