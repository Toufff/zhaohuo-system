# 趙活系統：《活俠傳》遊戲內修改器

[简体中文](README.md) | 繁體中文 | [English](README.en.md) | [한국어](README.ko.md)

《活俠傳》（Legend of Mortal）的遊戲內修改器，以 BepInEx 外掛的形式執行。進入遊戲後按 F8 開啟面板，可以：
- 查看這次行動會觸發哪些事件，並指定要觸發哪一個；
- 直接修改屬性和好感；
- 預先看到對話選項會帶來什麼結果；
- 指定骰子擲出的結果；
- 在戰鬥中開啟無敵、一擊必殺。

模組介面跟隨遊戲語言，支援繁體中文、簡體中文和韓文。

> 強烈建議第一週目不用任何模組，原版打到「最後的暗器」或「武林傳奇」結局後再用趙活系統：先嘗原作的設計，多週目才有回甘。本模組不會鎖任何功能，只在第一次開啟面板時提醒一次。

![行動前在面板裡查看這次可能觸發的事件，並指定其中一個](media/event-choose.webp)

## 功能

- **事件**：每次行動前，面板會列出這次可能觸發的事件和觸發條件。條件會附上目前的數值（例如「行動次數 3>=1」），已滿足的條件顯示為綠色。每個事件下面還會寫出觸發後的屬性、好感等變化，增加綠、減少紅。事件列表裡可觸發的事件排在前面。
  - 行動停下時，在清單裡選中一個事件再按「繼續本次行動」，這次就會觸發它；不選就和遊戲原本一樣隨機。
  - 條件還差一點時，可以按條件旁的「設為 N」，直接把數值改到滿足。
  - 行動停下時，如果這個行動上次指定過事件，可以按「重複上次選擇」一鍵再選同一個。
- **地圖**：地點旁會標出有幾個事件，有可以觸發的事件時，標記顯示為綠色。滑鼠移上去可以看到事件清單。設定頁可以單獨關掉地圖上的事件數字，其他提示照常顯示。面板「目前地圖」裡還有「不限地點」一組，列出不掛在任何地點上的任務和它們的條件。

  <img src="media/map-hover.webp" width="420" alt="地圖上的事件數標記和懸停清單">

- **一次性事件提醒**：地圖上每個地點，以及對話選項（例如路途中選路線），只要後面有現在就能觸發、觸發一次就沒了的事件，地點標記變綠，選項前面多一個綠色「●」。

- **跳過本旬**：自由行動的地圖上，以及自由行動階段選地點的劇情選單裡，日期右邊有「跳過本旬」按鈕：點一下變成「確定嗎？」，再點一次就放棄本旬剩下的行動次數，直接進入下一旬；主線劇情等你去某個地點時不顯示。跳過時會逐點檢查，途中有劇情要觸發就停下進入劇情。劇情裡的自由行動段（如雲裳線住破廟那幾旬）跳過後會回到原來的選單，不會跑去唐門地圖；有會推進主線的選項時不顯示這個按鈕。

- **本旬行動點無限**：日期右邊、「跳過本旬」旁邊有「本旬行動點無限」，點了這一旬的行動點不再消耗，到下一旬自動恢復。設定頁可以單獨關掉日期右邊的「跳過本旬」和「本旬行動點無限」兩個按鈕。

- **數值**：屬性、人物好感、門派關係、劇情標記都可以直接修改。「數值」頁每個數值旁有鎖按鈕，可以本次鎖定（重啟遊戲後解除）或一直鎖定（換存檔、重啟都保留），鎖住後劇情、物品、戰鬥都改不動它，面板裡手動改照樣有效。

  <img src="media/values-tab.webp" width="560" alt="數值頁">

- **六維上限**：設定頁「六維上限」可以把體力、內力、輕功、刀劍、暗器、拳掌的上限從 100 提到 200 或 999。原本被 100 卡住的加成會馬上算進去，人物會明顯變強。改回 100 後，超出的部分會在下次變動或讀檔時壓回 100。

- **對話選項**：選項後面會用括號寫出選了會怎樣，例如屬性增減、「若…」條件分支、劇情標記、隨機事件、擲骰。鎖住的選項（「解鎖條件：？？？」）後面會顯示真正的解鎖條件和目前數值，以及解鎖後的效果。滿足條件就直接接一段劇情的分支，括號裡會寫「若 條件：觸發劇情」。鎖住的選項旁有「一鍵設定」，把沒滿足的解鎖條件直接改到滿足，選項當場解鎖。解鎖條件是幾項數值相加比大小時（如六道加起來 > 1），差多少就補在其中一項上。
  - 整個模組裡顏色只有一種含義：綠色表示條件滿足、數值增加或獲得物品，紅色表示條件不滿足、數值減少或失去物品。
  - 滑鼠移到選項上，可以看到完整的條件和具體標記。

  <img src="media/options.webp" width="560" alt="選項後的結果概述和懸停詳情">

- **被隱藏的選項**：議題、走訪等選單的標題旁顯示「另有 N 個選項未滿足條件」，點開看被遊戲隱藏的選項和各自的解鎖條件（紅綠標註，永不出現的標灰）。用本模組改了數值或標記後點這個按鈕，已滿足條件的選項會直接出現在選單裡。可在設定裡關閉。

- **劇情分支**：劇情依標記或條件分支時，遊戲視窗左下角會跳出小框，列出每個分支的條件和目前的數值，並標出這次走的是哪一支。出現或更新時會彈一下、標題閃爍提醒。小框可以拖動，也可以關掉；拖到別處後位置會記住，設定頁「重置位置」可以放回左下角。不想看到小框時，可以在設定頁關閉「顯示劇情分支小框」，其他懸浮顯示不受影響。劇情按條件分支時，回想裡也會在當時的位置記下走了哪支：預設每組一行，滑鼠移上去看完整條件和目前值；設定頁「回想中的劇情分支」可以改成完整或不顯示。同一行有【回到這段開頭】（選存檔格後從這段劇本開頭重來）和【決定它的選項】（列出劇本裡設置這些標記的選項，收錄過的可以直接跳回去重選）。沒走過的路線也能在【決定它的選項】裡點「按此改標記」：把標記改成該選項給的值，從分支所在那一段開頭重播，讓遊戲重新判定（只改這一個標記）。

  <img src="media/branch.webp" width="620" alt="劇情分支小框">

- **骰子**：每個結果旁都有「指定 N%」按鈕，按哪個就擲出哪個，N 是這一檔原本的機率。加成太高或太低、正常擲不出來的結果（顯示 0%）也能選，骰面會依總點數倒推，算式照樣對得上。不按的話，就是遊戲原本的隨機。按「指定」後預設直接出結果，不播轉盤、不等「繼續」，結果仍由遊戲結算；想要原來的流程，可以在設定頁關掉「指定後直接出結果」。

  <img src="media/dice.webp" width="520" alt="按「指定 0%」後，轉盤停在正常擲不出來的那一檔">

- **彈珠台**：「總分」下面有「總分改為： 100 60 30 0」。彈珠台之後的劇情只看總分落在哪一檔（100 以上、60 以上、30 以上、更低），點一下就改成對應的分數，再點遊戲的「離開」即可。

- **商店**：道具說明下方會多一行實際效果。

  <img src="media/shop.webp" width="560" alt="道具說明下的效果行">

- **戰鬥**：無敵、一擊必殺、氣力不減、技能無冷卻，即時戰役和回合制決鬥都能用。這些開關只在戰鬥中生效，不會寫入存檔。「雙方最低 1 血」（僅決鬥）：雙方的血都不會低於 1，適合要拖回合的決鬥。戰鬥中畫面頂部有「直接勝利」「直接失敗」兩個按鈕（點兩下確認），按遊戲自己的結算直接結束戰鬥，方便快速走不同支線。有僵持結局（打到某一回合自動結束、不分勝負）的回合制決鬥，兩個按鈕中間還有「直接僵持」，按遊戲自己的僵持事件結束。戰役中遊戲會鎖住滑鼠，按鈕在暫停（Esc）時出現。決鬥畫面右下角，遊戲內建的加速按鈕上方可以選 2×（原版）、3×、4×，加速按鈕打開時按選中的倍數。回合之間的等待也縮短了，身上狀態越多越明顯，效果和結算不變。

  <img src="media/battle-tab.webp" width="560" alt="戰鬥頁開關">

- **收集**：面板的「收集」頁列出講經堂裡的風雲史、生死簿、汗青書，可以逐項解鎖，也可以整類「全部解鎖」。風雲史會一併解鎖對應的 Steam 成就，和遊戲裡正常解鎖一樣，解鎖後無法撤銷。

- **劇情中隨時存檔**：劇情裡任何時候都能用遊戲內建的存檔，包括選項和骰子出現前。存下的是目前這段劇情開頭的狀態，讀檔後從這段開頭重播，數值不會重複計算。讀檔時還會補放這一段開始時的背景音樂和環境音。

- **劇情回顧**：面板「回顧」頁會自動收錄有選項、擲骰或戰鬥的劇情段開頭的進度（每段留最新一份，☆ 收藏的那份不會被覆蓋），並標出沒看過的分支（「未讀」「部分已讀」，全部周目都算）。選中一段點「跳轉」，選一個存檔格（空格，或確認後覆蓋已有存檔），寫好後直接進入那一段的開頭，去走當時沒選的分支。在標題畫面也能打開面板使用「回顧」頁（收錄節點、劇情樹、路線圖，依最近存檔顯示）。

- **劇情樹**：「回顧」頁切到「劇情樹」，按主線任務的日期列出主線劇情的段落和每個選項、擲骰、條件、戰鬥前後的去向，點開一層看下一層。

- **劇情路線圖**：「回顧」頁切到「路線圖」，主線按遊戲日曆畫成車道和站點，襄陽行、葉雲裳 · 山洞九日、雪山行畫成會改走主線的岔路站，序章畫成讀回的一圈。顏色表示讀過多少，藍圈是這一局走過的站，金圈是下一站。點開一站可以看小節和岔路的進入條件、從這裡岔出去的支線；支線按怎麼進入分三組。可以按人物、地點、事件、台詞搜尋，也能查看沒畫在時間軸上的閒聊、地點和會議事件。地圖可以拖動、縮放（Ctrl + 滾輪或上方 −、+），Shift + 滾輪左右移動；上方有主線分岔點的快捷按鈕，地圖和說明欄之間的豎線可以拖動調整寬度。選中站點或支線後，有收錄進度的（地圖上帶 ▶）可以「跳轉」直接進入，沒有的可以「直接跳轉」（缺少中間劇情的標記，可能出錯，會先提醒）；點「說明」看詳細規則。第一次打開約需 6 秒。

  <img src="media/route-map.webp" width="720" alt="劇情路線圖：主線依遊戲日曆排開，上方是分岔點快捷按鈕">

- **存檔排序**：讀檔、存檔頁的手動存檔可以依「編號」「最新在前」「最早在前」排列，按鈕在「手動存檔」（讀檔頁）或「儲存遊戲」（存檔頁）右邊，空格排在最後。讀檔頁和存檔頁會各自記住上次用的排序。排序還可以選「收藏優先」，帶星號的存檔排在最前。還有「最早在前（排除收藏）」，沒帶星號的存檔從早到晚排在前面，帶星號的排在後面。

- **存檔收藏與備註**：讀檔頁和存檔頁的手動存檔可以加星號收藏、寫備註，用來區分存檔；收藏和備註存在模組自己的檔案裡，不改存檔。星號和備註跟著存檔走：新存檔寫進某一格時，這一格原來的星號和備註會一起清掉。覆蓋收藏的存檔前會再確認一次。移除模組會一併刪掉收藏和備註。

- **手動存檔 50 格**：手動存檔從 20 格擴充到 50 格，設定頁「手動存檔數」可以改為 20–99，下次打開讀檔或存檔頁時生效。調小或移除模組後，多出的存檔不會出現在遊戲的存檔列表裡，但檔案仍在，調回或重新安裝即可看到。

- **存檔功能**：設定頁「存檔功能」預設開啟。關掉後本模組的存檔相關功能全部按原版——不能在劇情中隨時存檔，讀檔、存檔頁只顯示 20 格，不顯示排序、收藏和備註；第 21 格以後的存檔、收藏和備註都不刪，重新開啟即恢復。

- **介面縮放**：4K 等高解析度下會自動放大，設定頁的「介面縮放」還能再調大調小。

- **介面風格**：設定頁「介面風格」可選「遊戲素材」（預設）或「簡潔」。「遊戲素材」用遊戲自己的邊框、按鈕和字體繪製面板與模組按鈕（素材取自遊戲已載入的資源，模組不附帶遊戲檔案）；「簡潔」是原來的純色樣式。劇情分支小框、戰鬥結果按鈕、決鬥加速按鈕、選項說明、地圖事件數字和存檔備註視窗也一起換樣式。

- **設定搜尋**：設定頁頂部有搜尋框，輸入文字即可依設定的名稱和說明篩選。

- **劇透類顯示**：設定頁最上面的「劇透類顯示」一鍵開關劇情分支小框、地圖事件數字、被隱藏的選項和回想中的劇情分支；只開了一部分時顯示「部分開啟」。

- **流程提速**：回到自由行動地圖、打開存檔讀檔頁和快進劇情都更快（不再反覆整份讀取存檔，快進時不再在指令銜接上空等），對話紀錄也不再每句重建。自動播放會等台詞完整顯示後再依字數翻頁。設定頁的「數值變化停頓」（0.5 秒原版 / 0.2 秒 / 不停頓）和「自由行動過場」（原版 / 加快 3 倍）可以進一步加快節奏，預設保持原版。

- **全域加速**：整個遊戲按 1.5 / 2 / 3 倍變快，劇情、自由行動地圖、回合制決鬥和即時戰鬥都生效（戰鬥裡疊加在遊戲自己的速度上，暫停照舊）。背景音樂不變，自動播放仍留足閱讀時間。可在設定頁綁定開關快捷鍵（預設不綁定）。

- **本次取消上限**：修煉、鍛造、煉丹面板裡「最大消費」右邊有個「本次取消上限」按鈕，點了之後這次打開就不限次數（顯示 ∞），關掉再進來恢復原本的上限；點數和銀兩照常消耗。

- **截圖**：可以一鍵隱藏模組的全部介面，也可以為它設定快捷鍵。

## 安裝

基於 Steam 版 build 26073097 開發與測試。

1. 從 [Releases](https://github.com/Toufff/zhaohuo-system/releases) 下載最新的 `ZhaoHuoSystem-v*.zip`，解壓縮到任意資料夾。
2. 關閉遊戲，按兩下 `install.bat`。
   - 它會自動找到 Steam 裡的《活俠傳》；找不到時會跳出視窗，讓你選擇遊戲資料夾（有 `Mortal.exe` 的那個）。
   - 遊戲還沒有 BepInEx 時，會一併安裝壓縮檔裡附帶的官方 BepInEx 6.0.0-be.788（Unity.Mono，Windows x64）。
3. 啟動遊戲，讀取存檔後按 F8 開啟面板。

修改數值和指定事件都會寫入存檔，第一次使用前請先備份存檔。

- **更新**：下載新版本，再按兩下一次 `install.bat`。
- **解除安裝**：按兩下 `uninstall.bat`。它會刪除外掛和設定，然後詢問是否一併刪除 BepInEx；其他 BepInEx 模組也依賴它，直接按 Enter 就會保留。存檔不受影響。
- 如果 Windows 跳出安全性提示，確認執行即可。

### 手動安裝

1. 在 Steam 收藏庫中對《活俠傳》按右鍵 → 管理 → 瀏覽本機檔案，開啟遊戲資料夾（有 `Mortal.exe` 的資料夾）。
2. 下載 [BepInEx-Unity.Mono-win-x64-6.0.0-be.788](https://builds.bepinex.dev/projects/bepinex_be/788/BepInEx-Unity.Mono-win-x64-6.0.0-be.788%2B5b766a3.zip)，把壓縮檔裡的全部內容解壓縮到遊戲資料夾。
3. 把 `ZhaoHuoSystem-v*.zip` 也解壓縮到遊戲資料夾，外掛會位於 `BepInEx/plugins/ZhaoHuoSystem/`。
4. 進入遊戲並讀取存檔，按 F8 開啟面板。

- **Steam Deck / Linux**：只能手動安裝，並在遊戲內容的啟動選項中填入 `WINEDLLOVERRIDES="winhttp=n,b" %command%`。
- **手動解除安裝**：刪除 `BepInEx/plugins/ZhaoHuoSystem` 資料夾。如果要連 BepInEx 一起移除，再刪除遊戲資料夾裡的 `BepInEx`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 和 `changelog.txt`。

## 使用

- **開啟面板**：按 F8，或點擊畫面左側的「趙活系統」小按鈕。快捷鍵可以在「設定」頁修改，小按鈕可以拖曳。
- **設定檔**：設定儲存在 `BepInEx/config/local.zhaohuo.system.cfg`。

## 遊戲更新之後

遊戲更新後外掛照常運作，小更新一般不影響使用。如果更新後出了問題，可以先按兩下 `uninstall.bat` 解除安裝，再到 [Issues](https://github.com/Toufff/zhaohuo-system/issues) 回報，修好後會發布新版本。

## 回報問題

請在 [Issues](https://github.com/Toufff/zhaohuo-system/issues) 中說明遊戲語言、在哪個場景出的問題、大約什麼時候發生的。然後在面板「設定」頁按「匯出診斷」，把匯出的資料夾壓縮後附上（路徑會自動複製到剪貼簿）。

## 從原始碼建置

需要準備：
- Windows；
- [.NET SDK 9](https://dotnet.microsoft.com/download)；
- 一份已經安裝好 BepInEx 的遊戲。

外掛在編譯時會直接參照遊戲資料夾裡的組件，不會複製這些檔案。

```powershell
# 遊戲不在預設路徑時，用 -p:GameDir 指定遊戲資料夾
dotnet build src/ZhaoHuoSystem/ZhaoHuoSystem.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\LegendOfMortal"

# 不需要遊戲的測試，CI 也會執行這兩項
dotnet run --project tests/ui-state -c Release
dotnet run --project tests/localization -c Release -- .

# 需要本機遊戲的測試
dotnet run --project tests/native -c Release -p:GameDir="D:\...\LegendOfMortal" -- "D:\...\LegendOfMortal"
```

建置結果是 `src/ZhaoHuoSystem/bin/Release/netstandard2.0/ZhaoHuoSystem.dll`，把它放進 `BepInEx/plugins/ZhaoHuoSystem/` 即可。
