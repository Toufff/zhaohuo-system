ZhaoHuo System v{VERSION} - in-game trainer for Legend of Mortal
================================================================

Built for the Steam release, build 26237817. Small game updates usually don't affect it; if something breaks after an update, uninstall it and report the problem.

ONE-CLICK INSTALL
1. Close the game.
2. Double-click install.bat in this folder.
   - It finds Legend of Mortal in your Steam library by itself. If it can't, a window opens so you can choose the game folder (the one with Mortal.exe).
   - If the game doesn't have BepInEx yet, it also installs the official BepInEx 6.0.0-be.788 included in this package.
3. Start the game, load a save and press F8, or click the small 赵活系统 button on the left edge of the screen.

Edited values and chosen events end up in your save, so back up your saves before the first use.
If Windows shows a security prompt, confirm that you want to run it.

UPDATE: download the new version, extract it and double-click install.bat again.

UNINSTALL: double-click uninstall.bat. It removes the plugin and its settings, then asks whether to remove BepInEx too. Pressing Enter keeps it. Your saves are not affected.

MANUAL INSTALL (use this on Steam Deck / Linux)
1. In your Steam library, right-click Legend of Mortal -> Manage -> Browse local files to open the game folder.
2. Extract everything in installer/BepInEx-Unity.Mono-win-x64-6.0.0-be.788+5b766a3.zip into the game folder.
3. Copy the BepInEx folder from this package into the game folder, merging it with the existing BepInEx folder.
4. Steam Deck / Linux: set the game's launch options to WINEDLLOVERRIDES="winhttp=n,b" %command%

TROUBLESHOOTING
- F8 does nothing in game: check that BepInEx/LogOutput.log exists in the game folder. If it doesn't, BepInEx is not installed; run install.bat again. If it does, report the problem as described below.
- Report a problem: https://github.com/Toufff/zhaohuo-system/issues
  Include your game language, what you were doing, and the folder created by the 导出诊断 (Export diagnostics) button on the 设置 (Settings) tab, or BepInEx/LogOutput.log.
